🎥 Cloudinary Video Setup for Your Portfolio

Step 1: Create Cloudinary Account

  1. Go to cloudinary.com
  2. Sign up for a free account
  3. Note down your Cloud Name from the dashboard

Step 2: Upload Your Video

  1. In your Cloudinary dashboard, click "Media Library"
  2. Click "Upload" → "Video"
  3. Upload your Reel_24-25_NicolaBergamaschi_V3.mp4 file
  4. Once uploaded, note the Public ID (usually the filename without extension)

Step 3: Update Your HTML

In your index.html file, replace:

  • your-cloud-name → Your actual Cloudinary cloud name
  • your-video-public-id → Your video's public ID (e.g., "Reel_24-25_NicolaBergamaschi_V3")

Example:

If your cloud name is myportfolio and public ID is showreel-2024, replace:

https://res.cloudinary.com/your-cloud-name/video/upload/f_auto,q_auto/your-video-public-id.mp4

With:
https://res.cloudinary.com/myportfolio/video/upload/f_auto,q_auto/showreel-2024.mp4

Step 4: Benefits You'll Get

  • ✅ Automatic optimization - Different quality/format per device
  • ✅ Global CDN - Fast loading worldwide
  • ✅ Multiple formats - MP4, WebM for browser compatibility
  • ✅ Reliable hosting - No GitHub Pages LFS issues
  • ✅ Same video controls - Native HTML5 video player

Step 5: Deploy

  1. Commit and push your changes to GitHub
  2. Your video will load reliably on GitHub Pages
  3. Test on different devices and browsers

🎯 Current HTML Structure

Your video element will maintain:

  • Same id="cg-video" for JavaScript compatibility
  • Same controls attribute for native video controls
  • Same data-hover and data-index attributes
  • Multiple source formats for maximum compatibility
  • Fallback download link
