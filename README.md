## My first website... must be my website.
This is my very first project developing my personal website as a place where gathering images I made throughout many years of artistic practice.

The webiste has been developed using HTML CSS and Vanilla Java Script while studying full-stack development course at LeWagon.

The website navigation occurs mainly through horizontal and vertical carousel which allows the user to select and switch between three different category: AI, CGI and Photo while the horizontal carousels allow the user to navigate within the category selected moving between a projects.

A cursor was created in order to give the user a visual reference regarding the current project selected and the amount of pictures left before jumping on to the following project. In a similar fashion a in line menu was placed at the bottom of the page functioning as aproject bookmark indicating the current position within categories and projects.

The mobile version is stripped of some functionalities such as the bookmark menu in order to emphasis the size of the images while reducing the UI at the bara minimum avoiding fingers to crossing the screen to press buttons.

The project is currently WIP, the selection of pictures is for now limited and the written content is a placeholder, however the functionality are working as excepected.
